# UniUni 渥太华仓 Incident 处理

每天处理客服/商家投诉（incident）的资料和工具。

## `index.html` — Incident 处理台

一个单文件网页：把官网页面 Ctrl+A 复制的文字粘进去，自动解析成卡片，产出三样东西。

**怎么用**

1. 在官网 incident 列表页 / Edit Order 页面按 `Ctrl+A`、`Ctrl+C`
2. 粘到左边的框里 → 点「解析」（一次粘多个单也行，同一个单粘几遍只会出一张卡）
3. 卡片上选场景模板，填一下照片里才看得到的东西（比如 POD 上的 unit）
4. 复制三个输出：

   | 输出 | 用途 |
   |---|---|
   | ① 发给中介的消息 | 直接粘进 WhatsApp |
   | ② 表格行（10 列） | 粘进 Google Sheets 自动分列，**颜色一起带过去** |
   | ③ 官网 Notes | 粘进 incident_form 的 Notes |

   卡片右上角那个橙色按钮**按三下就完事**：第一下复制消息、第二下复制表格行、
   第三下复制 Notes **并自动关单**（卡片移掉、粘贴框清空）。旁边三个点显示走到哪了。
   每个输出旁边也各有自己的复制按钮，想单独重来都行。

   有群链接的中介（Christ / Kaneza / Alawi / Parfait），第一下会**顺手把群打开**，进去 Ctrl+V 就行。
   Alain 和个人司机暂时没链接，就只是普通复制。
5. 三步走完自动关单；也可以随时手动点「关单」——都会顺带清空左边的粘贴框

**群链接**：Christ / Kaneza / Alawi / Parfait 的群已经内置。缺的（Alain、Company driver）在右上角
「群链接」里补一次就行（WhatsApp → 群资料 → 邀请链接 → 复制），存在浏览器本地；在那里填的会覆盖内置的。
中介留空 = 个人司机，走 Company driver 群。

**司机怎么显示**：卡片头是「司机号 + 名字」——中介的司机跟中介名（`32108 Alain`），
个人司机跟自己的名字（`18844 Ismail`，取自排班表；名单外的用订单里解析出的司机名）。
消息里不重复写司机号，`19993-94` 那一行已经带了。

**Shein 单会自动切成简洁版消息**：Shein 直接记丢，记丢就不能再修复，所以消息里不含收件人、
电话、邮箱、地址——避免司机拿着客户信息去「修复」。卡片会标红提示。

**表格 10 列**：今天日期 · Delivery date · 名字 · 中介 · Driver ID · Parcel# · Parcel ID ·
地址 · 是否记赔 · 原因。

第 3 列和第 9 列的选项直接来自表格的数据验证，一字不差（注意 `Fixed/no penality`、
`Warehouse relarted` 是表里原本的拼法），粘进去才会匹配上下拉并自动套色：

- **名字**：右上角选，默认 Lin，会记住
- **是否记赔**：21 个选项，「常用」组放了 15 / 12 / 留空 / Fixed，其余按表格顺序排在「其他」组。
  默认值按规矩来：**Shein 单直接记红色的对应项**（POD 不合格 → 15、送错地址 → 12），
  意味着记丢；**非 Shein 留空**，5 天后再定司机要不要赔——红色就是要赔钱。
  破损/漏液当场就定不扣钱，默认给 `Fixed/no penality`。
  填得跟规矩不一样时，卡片上会用红字提醒一句

表格行预览用的就是 Sheets 里那套 chip 配色（Lin 蓝、Jasper 深紫、Baldwin 黑、Nicholas 红、
15/12 红底白字、16 蓝底、4x 补贴绿底、Fixed 白底），预览长什么样，粘进去就是什么样。

复制出去的 HTML 里，「是否记赔」那一格是**居中 + Arial 12 + 带底色**；名字那一列
**不填背景色**（交给表格自己的下拉 chip 上色），两列都不加粗。

复制表格行时剪贴板里同时放了两份：`text/html`（带底色的表格）和 `text/plain`（TSV）。
Sheets 优先读 HTML，所以**底色跟着一起过去**，目标行没有下拉规则也照样有颜色，不用再往下拖格式；
粘到记事本、WhatsApp 这类地方读到的仍然是纯文本。

**中介列**内置了 444 个司机 ID 的对应关系，来自「渥太华问题订单管理.xlsx」和「YOW dispatch
schedule」（2026-08-13 提取）。名单里没有的司机，手填一次就会记住；点右上角「名单」可以粘贴
`司机ID + 中介名` 批量更新。中介名留空 = 个人/仓库司机。

**其他**：卡片、群链接、名单改动都存在浏览器本地，刷新不丢，卡片隔天自动清空。
解析成功后粘贴框会自动清空。右上角可切深色/浅色。

### 打开方式

- 直接双击 `index.html`
- 或挂 GitHub Pages：仓库 Settings → Pages → Source 选 `Deploy from a branch`，
  分支选 `main`、目录 `/ (root)`，几分钟后就能用链接打开

### 范围

目前只针对 **DELIVERED** 的单（POD 不合格、送错地址这类，占 incident 绝大多数）。
断更、未妥投那套模板还没做，状态不是 DELIVERED 时卡片会提示。
